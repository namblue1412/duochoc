2) Câu lệnh nhanh

Hãy tạo file JSON theo TEMPLATE:
- Môn: Dược lý – Hệ giao cảm, kháng cholinergic
- Số câu: 50 (35 single, 15 multi)
- Độ khó: 50% easy, 40% medium, 10% hard
- time_limit_sec=2400, shuffle_questions=true, shuffle_options=true, pass_mark=0.6
- id DL001…DL050; mỗi câu có explanation ngắn; chỉ trả JSON hợp lệ.
Tôi gửi danh sách Q/A (A/B/C/D + đáp án đúng). Hãy CHUYỂN thành JSON TEMPLATE.
- Single nếu 1 đáp án đúng; Multi nếu >1
- Giữ nguyên câu hỏi/đáp án, explanation ngắn
- id DL001…; difficulty=medium nếu không suy ra
Tạo đề LUYỆN SAI từ JSON cũ với ids: [DL002, DL015, DL021,…]
- Giữ nội dung, đảo thứ tự đáp án
- title = "Luyện sai – [tên cũ]"; shuffle_options=true
